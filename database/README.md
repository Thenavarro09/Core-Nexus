# Scripts de bases de datos

Core-Nexus no está atado a un esquema. Esta carpeta guarda scripts opcionales para poblar una instancia de SQL Server y probar la suite.

El ejemplo previsto del curso es el esquema de una Agencia de Viajes. Cuando exista, colócalo aquí (por ejemplo `agencia_viajes.sql`) y ejecútalo en la instancia que quieras monitorear. La aplicación sigue funcionando con cualquier otra base: en la pantalla de Conexiones se elige el servidor y la base, y `master` permite listar las bases de la instancia.
